# 🎮 KYRO SNES

**A new way to experience classic Super Nintendo games on Windows.**

KYRO SNES is a Windows application designed to bring the Super Nintendo Entertainment System (SNES) experience to modern computers through a standalone executable.

Simple, lightweight, and designed with attention to performance and user experience.

---

## 🚀 Download

**Latest version: 1.0.0**

[⬇️ Download KYRO SNES 1.0.0](../../releases/latest)

**Executable:** `Kyro-SNES-Port-1.0.0.exe`

### Installation

1. Download the executable from the Releases page.
2. Save it to your Windows computer.
3. Run `Kyro-SNES-Port-1.0.0.exe`.
4. Follow the application's instructions.

## ✨ Features

- Windows standalone executable.
- Super Nintendo game compatibility.
- Designed for a simple and intuitive experience.
- Keyboard/controller support, depending on the implemented configuration.
- Focus on performance and responsiveness.

*Features and compatibility may vary depending on the current build.*

## 💻 System Requirements

- **OS:** Windows 10 or Windows 11 (64-bit).
- **Architecture:** x64.
- **Storage:** Space required for the application and game files.
- **Input:** Keyboard or compatible controller.
